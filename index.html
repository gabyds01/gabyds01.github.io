THESIS PROJECT • IoT, AI & CLOUD ARCHITECTURE

AI-Based Monitoring & Early Warning System for Protected Areas

Thesis Firmware Backend Completed

Description: Designed and implemented an automated monitoring and early warning system for the Misiones Rainforest (Selva Misionera). The system combines low-power Internet of Things (IoT) camera networks with server-side Artificial Intelligence (AI) to automatically detect, classify, and report wildlife species, humans, and unauthorized vehicles in real time.

Technical Challenge: Overcoming the limitations of traditional camera traps to work without cellular network access or heavy battery setups in remote rainforest environments, while eliminating the delay and effort of manual memory card collection and manual image review.
Solution: Deployed ESP32-CAM nodes forming a self-healing 2.4GHz ESP-MESH-LITE network that routes images to a Root Gateway node. Built a containerized cloud backend via Docker featuring a Django control panel, a PostgreSQL database, a SpeciesNet (Google-backed YOLOv5) AI inference service for automated classification, and a Telegram Bot that delivers real-time notifications to forest rangers.
IoT / ESP32 ESP-MESH-LITE YOLOv5 / SpeciesNet Django / Python Docker PostgreSQL Telegram API C / C++

PROFESSIONAL PRACTICE • DESKTOP & BACKEND SYSTEMS

GaritaSystem (Martin Bauer Argentina)

Proprietary Completed

Description: Designed and developed critical production modules for "GaritaSystem", an enterprise weighing and truck cargo registration system implemented at Martin Bauer Argentina. Designed a multi-workstation client-server architecture including desktop PySide6 clients, containerized Django REST services, and seamless integration with the Softland ERP system.

Technical Challenge: Completing the operational cycle by creating secure, constraint-validated edit mechanics for active load processes while preventing any modifications to finalized weighing records, and dynamically rendering high-fidelity printer-ready PDF tickets with zero performance latency on remote local terminals.
Solution: Programmed secure PySide6 GUI edit dialogs that load pending weighing records. Created a Django REST API endpoint (`/api/generate-ticket/`) that queries PostgreSQL and dynamically generates formatted weighing tickets with WeasyPrint. Implemented automated silent printing on the client side using native OS printer spooling pipelines in Qt, integrated with the corporate Softland ERP.
PySide6 / Qt Django REST Framework WeasyPrint PDF PostgreSQL Softland ERP Docker Network Printing System Integration

ROBOTICS • CONTROL THEORY & SCIENTIFIC PYTHON

VSSS PC Control System

Repository Standby / Core Dev

Description: Engineered the core design and initial codebase of the PC-side real-time control loop for Very Small Size Soccer (VSSS) autonomous robots. Translates raw vision sensor telemetry into precise wheel velocities in closed-loop systems. This work serves as the foundation for a co-authored scientific robotics paper.

Technical Challenge: Implementing highly reliable closed-loop trajectory tracking (unicycle kinematic conversion to differential drive wheel speeds) under microsecond-level timing constraints on standard PCs over unstable wireless interfaces.
Solution: Implemented a modular Python package with LQR tracking (Kanayama error projection, wall gain-scheduling) and Pure Pursuit controllers. Built curvature-adaptive speed controllers, parametric spline/S-curve path generators, asynchronous Protobuf UDP vision deserialization, ESP32 USB-serial bridge packaging with CRC-8, and live telemetry profiling tools.
Theory of Control LQR / Pure Pursuit Kinematics Model Python / uv Protobuf / UDP Matplotlib / Numpy ESP-NOW / Serial Scientific Computing
